Lecteur

Morceaux dans le FM-1
Où trouver des musiques ?

Ces sites proposent les bandes son de jeux au format VGM, souvent en packs .zip d’un jeu entier : choisis directement le .zip ici, puis le morceau dans la liste.

  • VGMRips : la plus grande collection. Par console : Game Boy, NES.
  • SMS Power : Master System et Game Gear.

ROMsounds joue les puces YM2612, SN76489 (PSG Sega), Game Boy DMG et NES APU. Les packs « FDS » ou avec des puces de cartouche en plus (VRC6, N163…) jouent sans ces voies-là.

Sur le FM-1, pendant la lecture

  • Touches du clavier : couper ou remettre une voix, de gauche à droite (Mega Drive : FM 1 à 6, DAC, PSG 1 à 3, bruit ; Master System, Game Gear : PSG 1 à 3, bruit ; Game Boy : carré 1, carré 2, onde, bruit ; NES : carré 1, carré 2, triangle, bruit, DPCM). Allumée : la voix joue ; faible et un clin d’œil par seconde : elle est coupée.
  • Solo + touche : cette voix seule ; recommencer : toutes les voix.
  • Boucle, beat roll : tant que le bouton est tenu ; au relâché, le morceau reprend où il en est. Le beat roll se cale sur le tempo indiqué à l’envoi.
  • Vinyl brake : la platine ralentit jusqu’à l’arrêt ; PLAY (ou le même bouton) relance.
  • Les effets restent d’un morceau à l’autre ; « Tout remettre à zéro » les éteint.
  • Écho, boucle, beat roll et backspin : pour les morceaux de moins de 140 Ko (presque tous).

Installer un firmware

Coche la case ci-dessus pour activer les boutons « Installer ».

Un fichier .fwsc de l’appareil Firmware Felucca, Dinghy ou dérivé, ou firmware officiel M-VAVE non modifié (V15, V16).
Revenir au firmware officiel
  1. Télécharger FM-1.fwsc chez M-VAVE (toujours la dernière version).
  2. Le choisir dans « Un fichier .fwsc de l’appareil », puis Installer.
